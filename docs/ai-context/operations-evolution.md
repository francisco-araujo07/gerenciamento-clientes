# Operação e evolução futura

## Operação do MVP

- Revisar diariamente os leads com próxima ação atrasada.
- Ordenar a tabela de leads pela data da próxima ação.
- Usar o filtro `Atrasadas` para priorizar os contatos pendentes.
- Importar somente CSVs revisados e aprovados pela equipe.
- Tratar possíveis duplicados exibidos na prévia antes de confirmar a importação.
- Usar exclusão definitiva apenas para registros criados por engano; usar status para registros encerrados.
- Criar e remover acessos manualmente no Supabase; não haverá tela de administração de usuários no MVP.
- O administrador do Supabase será responsável pela exportação semanal e por guardar os backups em local privado com acesso controlado.

## Evolução após o MVP

- Automatizar mensagens iniciais para leads.
- Reavaliar os limites gratuitos de hospedagem e banco conforme o uso crescer.
- Adicionar novas funcionalidades somente após validar o uso do MVP pela equipe.
