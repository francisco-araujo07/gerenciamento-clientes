# Ordem de construção do MVP

1. Criar a base do projeto com Vite, React e a estrutura aprovada.
2. Configurar banco de dados, login e permissões no Supabase.
3. Construir a tela e a tabela de leads: cadastro, edição, filtros, busca e próxima ação.
4. Implementar a importação de leads por CSV.
5. Implementar a conversão de lead em cliente.
6. Construir a tela de clientes e os projetos vinculados.
7. Construir o dashboard de faturamento.
8. Revisar a experiência em computador e celular.
