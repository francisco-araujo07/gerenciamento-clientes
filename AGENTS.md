# Contexto de IA do projeto

Antes de criar, alterar ou revisar qualquer parte do projeto, ler `docs/ai-context/README.md`.

Carregar somente os documentos indicados para a tarefa. Não percorrer o projeto inteiro para obter contexto quando estes registros já forem suficientes.

Após uma alteração material, atualizar `docs/ai-context/current-state.md`, `docs/ai-context/change-log.md` e, quando aplicável, `docs/ai-context/activity-log.md` ou `docs/ai-context/decisions.md`.
